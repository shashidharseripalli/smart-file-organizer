# Smart File Organizer

Automatically organizes files in real-time using Python.

## Features
- Live folder monitoring
- Auto categorization (Images, Videos, Documents, Code, Archives)
- Duplicate removal
- Logging
- Streamlit dashboard

## Tech Stack
- Python
- Watchdog
- Streamlit

## Run

pip install -r requirements.txt
streamlit run dashboard/app.py

## Demo
Drop files into the watch folder → they auto organize instantly.
